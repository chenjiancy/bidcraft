# samples/ - 测试样本（公开）

> 本目录存放**公网公开的招标文件**样本，随仓库推送，无需脱敏。
> **投标文件等含敏感信息（企业证书、人员身份证、社保、合同等）的文件一律放入 `samples-local/`（已 gitignore，仅存本机），严禁放入本目录。**

## 目录结构

```
samples/
└── <项目名>/                    # 一个项目一个文件夹
    └── 招标文件正文.pdf          # 公网公开招标文件
```

3. 解析期望输出（清单 JSON 等黄金基线）不含敏感信息的可入库，存于对应项目文件夹。
