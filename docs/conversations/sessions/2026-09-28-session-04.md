## 一、任务范围（tasks.md Task 1）

4. 一键脚本：`npm run dev` 同时拉起 Renderer/Electron/sidecar；含 lint、test

7. 测试基础设施：Vitest + pytest（conftest 与隔离夹具基线）

9. 自动更新骨架：electron-updater + electron-builder（NSIS）依赖与最小配置入口

## 三、偏差与披露（重要）

1. **环境检测变量名与架构文档不符**：architecture.md 10.1 原写 `VITE_DEV_SERVER_URL`，实测 electron-vite v5 注入的是 `ELECTRON_RENDERER_URL`（源码确认）。首次 dev 启动误判为 prod（userData 落 BidCraftApp、spawn exe ENOENT）。已修正 [electron/main.ts] 与架构文档 10.1/10.2，并删除误生成的 BidCraftApp 空目录（仅 Chromium 缓存，无业务数据）。
2. **uvicorn 不接受 --data-root**：架构 10.2 示例 `uvicorn app.main:app --data-root` 会被 uvicorn CLI 拒绝。实现改为：dev 仅经 `BIDCRAFT_DATA_ROOT` 环境变量传数据根；`--data-root` 保留给打包后的 exe（app/core/config.py 同时支持两种来源 + 兜底）。
3. **Prettier 范围**：存量文档（.trae/docs/samples）不纳入 Prettier 门禁（加入 .prettierignore），避免旧文档重排污染 PR；CI `prettier --check .` 只校验代码文件。
4. **TestClient deprecation warning**：starlette TestClient 提示未来改用 httpx2；当前为 warning 不阻断，未引入新包，后续关注。
5. 黄金样本为占位基线（health 响应快照），真实招标文件样本在 Task 8 接入。
