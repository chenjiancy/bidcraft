## 一、任务范围（tasks.md Task 3）

1. Sidecar `/health`；随机端口 + 本地令牌；仅监听 127.0.0.1
2. Main 拉起/关闭 sidecar、健康检查轮询、崩溃检测（状态机）
3. preload 暴露 `sidecar:health/call/stream`、`task:cancel`
4. SSE 进度协议打通（确定性测试事件流：queued → progress×2 → completed；支持 cancelled 终态）

## 二、实现要点

**Python（FastAPI）**
- `app/core/security.py`：Bearer 令牌依赖，`BIDCRAFT_SIDECAR_TOKEN` 注入；未配置（裸跑 uvicorn）时放行
- `app/core/tasks.py`：内存任务注册表，承载取消信号（asyncio.Event）
- `app/api/test_events.py`：`POST /api/v1/test/stream`（SSE 事件序列，每步 100ms 取消窗口）；`POST /api/v1/tasks/{id}/cancel`
- `/health` 保持无鉴权（健康检查不要求令牌，architecture 2.2 明确豁免）

**Node（Electron）**
- `electron/lib/net-utils.ts`：操作系统分配空闲端口
- `electron/lib/sse.ts`：SSE 流解析（缓冲拼接、仅取 data 行、非法 JSON 抛出）
- `electron/sidecar.ts`：状态机 starting/healthy/crashed/stopped；启动后轮询 /health（30s 超时）；非主动退出标 crashed
- `electron/main.ts`：IPC 白名单 sidecar:health/call/stream + task:cancel；路由正则限定 `/api/v1/...` 防 SSRF；令牌仅 Main 持有，Renderer 不接触
- `before-quit`：preventDefault → 等待 sidecar 进程树结束 → 再 quit

## 三、偏差与披露（重要）

1. **未打包运行改直连 .venv uvicorn.exe**：Task 1/2 经 `shell:true` 跑 `uv run uvicorn`，进程树为 cmd→uv→uvicorn→python。实测退出时 taskkill 是异步发射、主进程未等其完成即退出，cmd 根先死导致整树孤儿（实测遗留 4 组共 20 个进程）。改为直接 spawn `.venv/Scripts/uvicorn.exe`（child.pid 即真实进程）+ 停止时 await taskkill 完成。architecture.md 10.2 已同步更新。
2. **sidecar 运行策略判别改用 app.isPackaged**：原 isDev（ELECTRON_RENDERER_URL）在 Playwright 直跑（electron .）时为 false，会去找不存在的打包 exe（Task 1/2 的 E2E 中 sidecar 实际静默启动失败）。现 spawn 策略取 `!app.isPackaged`；loadURL 仍用 ELECTRON_RENDERER_URL。
3. **TestClient 不支持并发请求**：取消流程无法用"流中再 POST cancel"测试（请求被串行阻塞到流结束）。改为单测直接驱动事件序列 async generator + 预注册任务验证取消端点；真实 HTTP 取消链路在 E2E（真进程）验证。
4. CI E2E job 增补 setup-uv + `uv sync --locked`（原先无 Python 环境）。
5. TestClient 的 StarletteDeprecationWarning（httpx2）仍为既有 warning，不阻断。
