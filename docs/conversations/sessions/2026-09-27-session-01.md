- **决策/产出**：

- **背景**：用户要求建立一套流程和机制，保障 AI 准确理解需求而无偏差；并硬约束未收到明确开始编码指令前不得编码。
- **决策/产出**：
  - 创建项目 skill：`.trae/skills/requirements-dialogue/SKILL.md`，定义「倾听 → 复述 → 追问 → 确认 → 落盘 → 推进」六步对话协议与编码冻结硬约束。
  - 创建项目规则：`docs/PROJECT_RULES.md`，与 skill 配套，含文档落盘分工、迭代规则、防偏差自检。
  - 将硬约束写入项目 memory（`project_memory.md`），跨会话持久化。
  - spec.md / checklist.md / tasks.md / 项目规则 / skill 均可迭代。
- **经验沉淀**：
  - 需求对话协议的核心是「复述 + 追问 + 确认」三步，强制暴露理解偏差。
  - 编码冻结规则必须同时落在 skill、项目规则、项目 memory 三处，确保不同入口都能触发。
  - PowerShell 不支持 bash heredoc，多行 commit message 需用多个 `-m` 参数。
