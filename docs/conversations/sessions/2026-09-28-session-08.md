#### Python 侧（sidecar）

- 新增 `app/parse/` 模块（9 文件）：
  - `paths.py`：项目隔离路径（source/sources.json/dedupe.json/chapters.json/parse/{raw,work,checkpoints}），safe_filename + 重名后缀

  - `checkpoint.py`：BP-1 原子 JSON Checkpoint（idle/running/success/error + attempts），running 崩溃回置 idle，单项重试级联清下游
  - `state.py`：parse_status 状态机（INIT/UPLOADED/PARSING/PARSED，取消/异常→UPLOADED 可续跑，每次转换写 app_event）
  - `service.py`：编排（登记→去重→转换→指纹→MinerU→章节→PARSED），SSE 进度权重 5/20/25/85/100，线程内运行 + 事件循环信号支持取消

### 披露项

1. **MinerU 独立环境不入库**：torch 2.11.0+cu128 等数 GB 重依赖装在 `sidecar/.venv-mineru/`（已 gitignore），不进 uv.lock、CI 不装；解释器经 BIDCRAFT_MINERU_PYTHON 或默认路径发现，不可用时前端禁用启动、不静默降级。
2. **环境补丁**：MinerU 3.4.5 遗漏依赖 `six`（OCR 链 import 失败），需 `uv pip install --python .venv-mineru/Scripts/python.exe six`；生产装机脚本/文档需纳入（Task 21 收尾时处理）。
3. **MinerU 许可证为自定义条款**（非标准 SPDX），产品分发前需法务复核。
4. **TR-8.5 用合成夹具**：样本库无真实"同名多格式"成套文件，测试用 shutil 复制 docx + LibreOffice 导出同名 pdf 构造，并对两者做文本指纹断言（same_content=True）。
5. **tests/engine 不进 CI**：CI 仅跑 unit/integration；真实引擎测试本机手工跑（无环境自动 skip）。
6. **MinerU 3.4.5 输出布局以实测为准**：`<out>/<stem>/<method>/<stem>_content_list.json`（method=auto/txt/ocr；非文档推断的 _v2 文件），引擎定位代码与单测均按实测布局。
7. **取消机制在事件循环内实现**：后台线程不跨线程注入取消事件（TestClient portal 线程模型下不可见），改由事件循环 call_later 注入；fake 引擎覆盖取消/并发拒绝路径。
8. **spec.md/tasks.md/tech-selection.md 的工作区改动为前序需求细化（Task 14-21 落盘）遗留**，将随本分支 PR 一并提交，如需拆分请指示。
9. tests/conftest.py:25 generator 返回类型 mypy 告警不影响 CI（CI 只 mypy app）；%TEMP%\bidcraft-inspect 为一次性观察产物，可删。
