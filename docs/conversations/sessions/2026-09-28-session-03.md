## 关键节点

### 节点 1：真实招标文件核验
- **输入**：和县柳庄路综合停车场工程监理《招标文件正文.pdf》（57 页，565KB）。
- **环境事件**：本机两个 Python 安装均损坏（Python314/venv 启动失败），改用 Node.js + pdfjs-dist（ESM）提取全文 3.8 万字。
- **核验结论**：文件实为**采购文件**（供应商/响应文件/报价函），综合评分法满分 50，费率报价（固定费率=金额/3010万），最高限价 30.10 万；FR-2 八项关键项全部命中，"评分点即目录"被实证；文件存在目录页码错乱、编号跳号、标题不一致等噪声。
- **经验沉淀**：真实文件的"脏乱"是常态，章节识别必须以正文实质内容为准。

### 节点 2：真实投标文件核验
- **输入**：7 份 docx（封面/报价函/两份偏离表/服务方案/法代证明授权书/资质资料），共 43 张内嵌图；用 mammoth + adm-zip 提取。
- **核验结论**：与解析格式 7 部分完全吻合；开标一览表未制作（系统生成）；人工做法揭示：落款统一开标日、偏离表留空即符合、监理大纲仅留 10 个评分点标题、散点附件汇集到"其他资料"、社保放人员力量末尾、报价函残留括号提示语。
- **数据核算**：配备 5 人满足最低要求；企业/总监业绩与荣誉可拿满对应评分。
- **经验沉淀**：人工成品的处理方式就是软件规则的最好来源；"提示语残留"应成检查项。

### 节点 3：联网调研 + 8 条工程建议
- **来源**：智标宝（DeepSeek+Qwen 双模型、企资库自动填充约 70%）、云境标书（200+ 要素规则、32 类废标风险）、中移动智能标书平台（600 条审核规则）、IJ Construction Management 2026 论文（F1 96.25%）、文档比对资料（docx 必须语义层比对）。

- NFR-1：仅 Windows 10/11，适配 1366×768 至 4K。
- NFR-2：本地解析 60 页 ≤10 秒、含 LLM ≤3 分钟；异步+进度+可取消；本期不限内存。
- NFR-3：API Key 用 DPAPI；本地文件不额外加密；不禁止外联、首次提示。

- NFR-5：中断恢复、原子写入、自动保存。
