## 过程中问题与处理
1. 镜像 alembic 最高仅 1.20.0 → 下限改为 >=1.14
2. env.py 直接 engine_from_config 不会建目录 → 迁移前显式 makedirs
3. 类体内 `list` 方法遮蔽内建类型导致 `list[ModelT]` 报错 → `from __future__ import annotations` + `builtins.list` 别名
4. ruff UP046 → 改用 PEP 695 `class ScopedRepository[ModelT: SoftDeleteMixin]`
5. E501 与 ruff format 对生成迁移的折行冲突 → 以 format 输出为准（单行 ≤100，不触发 E501）
6. **CI mypy 首红（本机漏跑该门禁）**：① TypeVar 用 Protocol 做 bound 时，SQLAlchemy Mapped 静态结构无法匹配（直接协议赋值可过、泛型实参检查失败）→ bound 改为名义类 SoftDeleteMixin（scope 模型均已继承）；② model.id/deleted_at 属性访问用 `cast(Any, ...)`。修复后本机 mypy/ruff/format/pytest 全绿

## 教训
本机提交前必须跑与 CI 一致的全部门禁（含 `npm run lint:mypy`），不能以"只改 Python 侧"为由跳过。
