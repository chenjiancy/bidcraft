# 对话记录目录

> 用途：沉淀 AI标书制作 项目开发过程中的关键对话节点，用于后续撰写开发总结与论文。

## 记录原则

- **关键节点摘要**：不逐字记录全量对话，只提炼对开发有价值的关键内容。
- **自动写入**：每轮对话结束后，由 AI 主动将关键节点追加写入。
- **可追溯**：每条记录带日期与编号，便于引用和检索。

## 记录结构

```
docs/conversations/
├── README.md          # 本文件：目录说明与记录规范
├── index.md           # 会话索引：日期、主题、关键产出
└── sessions/
    └── YYYY-MM-DD-session-NN.md   # 单次会话的关键节点摘要
```

## 单会话记录模板

每次会话记录遵循以下结构：

```markdown
# 会话 NN - YYYY-MM-DD - 主题

## 参与方
- 用户：chenjiancy
- AI：Trae

## 关键节点

### 节点 1：（简述该节点的核心事件）
- **背景**：（为什么发生）
- **决策/产出**：（达成了什么、创建了什么文件、做了什么选择）
- **经验沉淀**：（可复用的经验或教训）

### 节点 2：...

## 本次产出文件
- [路径](file:///...) - 说明

## 待办/后续
- （待处理事项）
```

## 节点分类

| 类别 | 说明 |
|---|---|
| 需求决策 | 用户明确的功能需求、范围界定 |
| 方案选型 | 技术方案、架构、工具链的选择及理由 |
| 实现动作 | 创建/修改了哪些文件、提交了什么代码 |
| 问题修复 | 遇到的问题、原因、解决方案 |
| 经验沉淀 | 可复用的经验、教训、最佳实践 |
