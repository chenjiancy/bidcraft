## 变更协议

编码过程中出现新需求或需求变更时：

```
暂停编码 → 记录变更请求 → 评估影响（哪些 FR/NFR/AC/Task/文档/代码受影响）→ 向用户披露影响 → 用户确认 → 同步更新所有受影响文档 → 记入本日志 → 恢复编码
```

- 不得边编码边口头调整
- 不得只改代码不改文档
- 不得跳过评估直接改
